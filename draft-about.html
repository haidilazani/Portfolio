Read the longer version

I’m Aidil, a computer science student at UiTM Shah Alam. I chose this path not knowing it would burn my brain and soul, yet I’m still standing here, and somewhere along the way it became mine.

The work is less poetic. In 2022 I took small freelance jobs as a junior developer, learning the difference between classroom code and code someone is waiting on. In 2023 I joined JustSimple Sdn. Bhd. as a frontend developer, building and maintaining client websites in WordPress and Elementor, and writing the custom CSS that Elementor couldn’t. Now I’m finishing my degree, with coursework across data science, machine learning and software engineering, and my final-year project is a tourism recommendation system in Flask that searches UNESCO World Heritage sites by meaning rather than keywords, using BERT sentence embeddings over an ontology of place categories.

I care about interfaces that feel calm and intentional: clean type, honest spacing, and motion that earns its place. I like knowing what every line does, which is why this site has no framework, no bundler and no dependencies. The contour map on my home page is ~1,390 lines of marching squares and value noise on a 2D canvas. When I’m not coding I’m behind a camera, collecting the moments on my Photography page.
