GeoTour, a semantic tourism recommendation system

01 / 03

2026 · Final-year project, Flask + NLP

A travel search engine that understands “quiet mountain ruins” instead of matching keywords: BERT embeddings over a 1,155-site UNESCO World Heritage dataset, plus an ontology graph you can explore.

  • Python
  • Flask
  • SQLAlchemy
  • sentence-transformers
  • NetworkX
  • pandas
Read the source

Keyword search fails travellers who describe the feeling of a place rather than its name, and destination datasets carry rich category metadata that plain text matching throws away.

A Flask + SQLAlchemy app encodes each point of interest as a rich document (name, ontology categories, description) with the all-MiniLM-L6-v2 sentence transformer, ranks queries by cosine similarity, filters by country names detected in the query, and ships a second Flask app that renders the category ontology as an interactive graph with a spreading-activation search (0.5 decay, up to 6 hops).

This portfolio

02 / 03

2026 · Personal site, vanilla web

Six pages, 9,950 lines, 103 KB gzipped of hand-written HTML, CSS and JavaScript: no framework, no bundler, no dependencies, including a topographic contour background drawn with marching squares.

  • HTML
  • CSS custom properties
  • JavaScript (ES6)
  • Canvas 2D
  • GitHub Pages
Open the live site Read the source

I wanted a portfolio I fully understood: no framework whose behaviour I couldn't explain in an interview, and nothing a recruiter's phone would have to download a megabyte of JavaScript to read.

Everything is written by hand: a theme toggle that sets data-theme before first paint to avoid a flash, a liquid nav indicator, scroll-reveal, a command palette and page transitions in one dependency-free script, and a canvas background that generates two value-noise fields, cross-fades them to make the terrain breathe, and traces five to nine elevation contours per frame with marching squares. Taps still ripple on touch; anyone who prefers reduced motion gets a single static render.

Live on GitHub Pages (HTTP 200) with zero dependencies and zero build step; total HTML+CSS+JS payload is 393 KB uncompressed, 103 KB gzipped, across 16 files.
